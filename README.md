# ❤️ Heart Pouch

Heart Pouch is a quality-of-life addon for the Heartstone mod.
It introduces a item that allows you to store, manage, and switch between multiple Heartstones in a single inventory slot.

No more inventory clutter. No more digging through chests or backpacks. One pouch, many bonds.

### ✨ What does it do?

Heart Pouch lets you:
- Store multiple Heartstones inside a single pouch.
- Instantly switch the active Heartstone using Shift + Mouse Wheel.
- Use the pouch as if it were the selected Heartstone.
- Safely add and remove Heartstones via inventory interactions.

All data is stored directly in the item NBT.

### 🎒 Features
- **Multiple Heartstones, one slot:**
Keep all your bound hearts together in a single pouch.
- **Scroll-based selection:**
Hold SHIFT and scroll to cycle through stored Heartstones.
- **Visual feedback:** Tooltips clearly show:  
  - Stored Heartstones  
  - Custom names (if present)  
  - Which Heartstone is currently active  
- **Inventory & container support:** Works seamlessly in any inventory or container.

### 🖱️ How to use
- **Insert a Heartstone:**
Right-click a Heartstone with the Heart Pouch inside your inventory, or vice versa, to store it. 
- **Remove the active Heartstone:**
Right-click the pouch with an empty cursor.
- **Switch active Heartstone:**
Hold SHIFT and scroll the mouse wheel while:
  - Holding the pouch
  - Hovering over it in an inventory/container
- **Use the pouch:**
Right-click normally to use the currently selected Heartstone.
